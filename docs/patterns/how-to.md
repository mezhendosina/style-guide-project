# Шаблон практического руководства

Используйте шаблон, когда читатель хочет получить конкретный результат. Замените текст в квадратных скобках и удалите неприменимые подсказки.

## Заголовок шаблона

````markdown
# [Глагол + объект]

[Одним абзацем: какой результат получит читатель и когда нужен этот сценарий.]

## Перед началом

Убедитесь, что:

- [условие доступа];
- [необходимый идентификатор или инструмент];
- [версия или ограничение].

## [Выполните основное действие]

1. [Одно действие.]
2. [Следующее действие.]
3. [Действие с проверяемым результатом.]

```bash
[полная рабочая команда]
```

API вернёт [ожидаемый результат]:

```json
{
  "id": "example_123",
  "status": "ready"
}
```

## Проверьте результат

[Как однозначно убедиться, что задача выполнена.]

## Возможные ошибки

| Ошибка | Причина | Что делать |
| --- | --- | --- |
| `[код]` | [условие] | [конкретное действие] |

## Что дальше

- [Следующая задача](../quick-start.md)
````

## Требования к готовому руководству

- Заголовок называет результат.
- Предварительные условия можно проверить до первого шага.
- Шаги идут в порядке выполнения.
- Команды копируются без исправления синтаксиса.
- После ключевого действия указан ожидаемый результат.
- Ошибки связаны с конкретными способами восстановления.
- Ссылки ведут к логичному следующему действию.
