# Структура документов

Предсказуемая структура сокращает поиск: одинаковая информация находится в одинаковом месте.

## Стройте страницу вокруг намерения

Одна страница отвечает на один основной вопрос. Заголовок называет задачу или объект без вводных слов.

- Для инструкции: «Создайте заказ».
- Для справочника: «Создание заказа» или `POST /v1/orders`.
- Для диагностики: «Заказ не создаётся».
- Для концепции: «Как работает идемпотентность».

## Начинайте с краткого ответа

Первый абзац объясняет, что даст страница и когда она нужна. Затем укажите предварительные условия. Не начинайте с истории продукта или определения очевидного термина.

Рекомендуемый порядок для практического руководства:

1. результат и область применения;
2. предварительные условия;
3. последовательные шаги;
4. проверка результата;
5. частые ошибки;
6. следующие действия.

## Соблюдайте иерархию заголовков

- На странице должен быть один H1.
- Не пропускайте уровень: после H2 используйте H3, а не H4.
- Не оставляйте пустой раздел.
- Не ставьте два заголовка подряд без вводного текста.
- Используйте не более трёх уровней в обычной статье.

Заголовок должен сохранять смысл вне контекста. «Ограничения запроса» полезнее, чем «Важно».

## Выбирайте список по смыслу

Используйте нумерованный список, если важны порядок или количество шагов. Используйте маркированный список для равноправных элементов. Начинайте пункты в одной грамматической форме.

Не помещайте единственный пункт в список и не продолжайте нумерацию через большие поясняющие разделы.

## Проектируйте ссылки

Текст ссылки должен описывать цель и читаться вне предложения.

- Неудачно: «Подробнее читайте [здесь](api.md)».
- Удачно: «Изучите [правила описания API](api.md)».

Не повторяйте URL как текст ссылки. Предупреждайте, если ссылка ведёт на загрузку большого файла или требует авторизации.

## Используйте таблицы для сравнения

Таблица подходит для однотипных параметров и сопоставления вариантов. Не прячьте в таблице длинные инструкции. У каждой колонки должен быть короткий заголовок, а пустое значение нужно объяснить: `—` означает «не применимо», а не неизвестное значение.
